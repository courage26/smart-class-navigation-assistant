### 프로젝트 소개

 Smart Class Navigation Assistant는 React Native와 Expo를 활용하여 개발한 모바일 앱입니다. 대학생들이 수업 시간표를 효율적으로 관리하고, 현재 수업과 다음 수업을 쉽게 확인하며, 적절한 출발 시간을 파악할 수 있도록 돕는 것을 목표로 합니다.

 특히 학생들이 수업 시작 직전에 급하게 이동하거나 지각에 대한 불안감을 느끼지 않도록, 다음 수업 정보와 출발 시간을 제공하여 보다 여유롭게 효율적인 캠퍼스 생활을 지원합니다. 

### 문제 정의

 대학생들은 수업 시간을 확인하기 위해 여러 어플이나 저장된 시간표 사진을 확인하는 경우가 많습니다. 또한 다음 수업 장소가 어디인지, 언제 출발해야 하는지를 매번 계산해야 하는 불편함이 있습니다.
 이러한 과정은 학생들에게 불필요한 스트레스를 유발하고, 늦은 출발로 인해 수업에 지각할 가능성을 높일 수 있습니다.
 
본 어플은 시간표를 한 곳에서 관리하고, 현재 수업 및 다음 수업 정보를 제공하며, 적절한 출발 시간을 안내함으로써 학생들이 보다 편안하게 이동하고 정시에 수업에 도착할 수 있도록 돕는 것으로 목표로 합니다.

### English Summary


## Project Overview

Smart Class Navigation Assistant is a mobile application developed using React Native and Expo. The application helps university students manage their class schedules, identify current and upcoming classes, and receive departure recommendations.


## Main Features

-Weekly timetable management

-Add and delete classes

-Current class detection

-Next class prediction

-Departure status recommendation

-Local data persistence using AsyncStorage


## Used Technolgy

-React Native

-Expo

-TypeScript

-AsyncStorage
